# Yaple (야플)
## 야구 입문 · 직관 메이트 플랫폼 (Web / Responsive)

야플(Yaple)은 **야구 입문자가 필요한 정보를 빠르게 습득**하고, **경기 직관 동행자를 안전하게 구하며**, 같은 팀/취향을 공유하는 사람들과 **소통**할 수 있도록 돕는 통합 웹 플랫폼입니다.  
(학습/정보)–(동행/연결)–(커뮤니티/소통)–(혜택/제휴)–(안전/모더레이션)을 한 흐름으로 연결합니다.

---

## 팀원 소개
김민규, 이선엽, 범윤준, 최재원

---

## 프로젝트 개요

### 1) 서비스 형태
- **웹 서비스 (PC/모바일 반응형)**

### 2) 핵심 대상(페르소나)
- **새싹(입문자)**: 팀/룰/용어/관전 포인트를 빠르게 배우고 싶음
- **선생님(숙련자/인증 사용자)**: 검증된 정보로 팀 위키를 편집하고 Q&A를 돕는 기여자
- **직관러(동행 모집/참여)**: 경기 조건 기반으로 동행을 찾고 매칭 품질을 높이고 싶음
- **관리자(운영/모더레이션)**: 신고/제재, 선생님 인증, 제휴 관리, 지표 모니터링

### 3) 핵심 가치
- **학습(정보)** · **연결(동행)** · **소통(커뮤니티)** · **혜택(제휴/굿즈)** · **안전(신고/경고/제재)**

---

## 배경(Problem)

야구 관련 정보는 검색/커뮤니티/SNS로 **파편화**되어 있어, 입문자(새싹)가 팀별 문화와 기본 개념을 **체계적으로 이해하기 어렵습니다.**  
또한 “같이 직관”을 하고 싶어도 낯선 사람과의 동행은 **안전/매너 관리 리스크**가 존재하고,  
경기 일정/결과, 굿즈/주변 상권 혜택 등 실사용 정보는 **한 곳에서 보기 어렵습니다.**

- 정보의 파편화
- 커뮤니티 진입장벽(초보 질문 비우호/신뢰성 이슈)
- 동행 리스크(안전/매너)
- 혜택 정보의 단절(주변 상권/굿즈/이벤트)

---

## 솔루션(Solution)

야플은 아래 4가지를 핵심 해결 방향으로 설계했습니다.

### 1) 팀별 위키 + 입문 가이드로 “학습” 진입장벽 최소화
- 검증된 **‘선생님’ 중심 편집**
- 팀/룰/용어/관전 포인트를 위키형으로 정리

### 2) 날짜별 경기 일정/결과 + 경기데이 커뮤니티로 “지금 필요한 정보” 제공
- 경기 전/중/후 분위기 공유
- 하이라이트 링크 등 외부 연동 확장 고려

### 3) 같이 직관(동행) 모집/참여 + 안전장치로 오프라인 동행 리스크 완화
- 모집/참여/확정 흐름
- 신고/경고/제재 정책으로 매너/안전 관리

### 4) 야구장 주변 혜택(맛집/놀거리/굿즈 할인)으로 재방문 동기 강화
- 반경 기반 추천(확장)
- 제휴 쿠폰/이벤트(확장)

---

## 주요 기능

### 1) 회원 기능
- 회원가입/로그인(일반 · 소셜 확장 고려)
- 응원 구단 선택/변경, 입문 단계(새싹/선생님) 설정
- 프로필 관리(응원팀, 직관 성향, 선호 구장/좌석, 자기소개)
- 신고/경고 누적 정책(누적 시 이용 제한/영구정지)

### 2) 페이지(서비스) 기능
- **새싹/선생님 지식 공유**
  - 선생님: 팀 정보 작성/업데이트(출처/근거 기반)
  - 새싹: 학습/질문(Q&A)
- **같이 보러 갈 사람(동행)**
  - 경기 기준(날짜/구장/팀/예산) 모집 · 참여
  - 매칭 후 후기/평가로 매칭 품질 개선
- **각 구단 특징**
  - 구단 성향/응원 문화/관전 포인트 안내
- **내 구단 정보(위키)**
  - 인증된 선생님만 편집 가능
  - 변경 이력/롤백 지원
- **경기 일정 및 결과**
  - 날짜별 일정
  - 경기 결과/하이라이트 링크(외부 연동)

### 3) 안전 · 운영(모더레이션)
- 게시글/댓글/채팅 신고
- 자동 필터링(욕설/도배) + 관리자 검수
- 경고 누적 단계화(예: 1회 경고 → 3회 7일 정지 → 5회 영구 정지) + 이의제기 프로세스
- 선생님 인증(기여도/신뢰도/운영자 승인) 및 권한 관리
- 개인정보/안전 가이드(오프라인 만남 체크리스트, 연락처 공개 최소화)

## 사용자 시나리오

- **새싹(입문자)**  
  회원가입 → 응원 구단(임시) 선택/입문 단계 설정 → 입문 가이드/팀 특징 탐색 → Q&A 질문 →  
  경기 일정 확인 → 직관 모집글 참여 또는 직접 모집

- **선생님(숙련자/인증 사용자)**  
  팀 위키 작성/수정(출처 기반) → 새싹 질문 답변 → 기여도에 따라 포인트/뱃지(확장) → 커뮤니티 품질 유지

- **직관러(동행 목적 사용자)**  
  경기 조건(날짜/구장/좌석/예산)으로 모집글 작성 → 참가자 프로필/신뢰 지표 확인(확장) → 확정 →  
  경기 전 안내/경기 후 후기·평가로 다음 매칭 개선

- **관리자**  
  신고 접수 → 증빙 확인(게시글/채팅 로그) → 경고/제재 처리 → 선생님 인증/위키 품질 관리 →  
  제휴/쿠폰 등록 및 정산 관리(확장) → 핵심 지표 모니터링
